# Cities2-MCP 0.2.0 release smoke

This report records pre-merge release smoke evidence for the automated release-versioning branch on July 11, 2026. It does not claim that `0.2.0` has been published, tagged, merged, committed to `mayor-modder/Mayor-Modder-Cities2-Plugins`, or served by the public Mayor Modder marketplace.

## Scope

The branch prepares Cities2-MCP `0.2.0`, generated plugin payloads, pull-request version automation, merge finalization, release publication handoff, and marketplace delivery automation. The smoke focused on local package integrity, generated catalog integrity, MCP startup from the generated Codex plugin payload, and the Codex client install path where available.

## Disposable marketplace payload simulation

This section describes a local simulation of the marketplace payload that the release workflow should eventually commit to `mayor-modder/Mayor-Modder-Cities2-Plugins`. It used a temporary checkout under `%TEMP%`; it did not push to or modify the real marketplace repository.

Commands:

```powershell
$catalog = Join-Path $env:TEMP 'cities2-mcp-0.2.0-catalog-smoke'
```

Observed result:

```text

```

The generated catalog checkout was `C:\Users\matt\AppData\Local\Temp\cities2-mcp-0.2.0-catalog-smoke`. Its changed files were the generated Cities2-MCP Claude and Codex package payloads and marketplace metadata; `cities2-chief-of-staff` remained present in the Codex marketplace list.

## Codex marketplace and installed-cache simulation attempt

This section describes a temporary local Codex marketplace configuration change that pointed Codex at the disposable checkout above. It was intended to test whether the generated local payload shape could be consumed before merge. It was not a test of the public marketplace, because the `0.2.0` marketplace PR cannot exist until after this source branch is merged and released.

After maintainer approval, the configured Codex marketplace was temporarily changed to the disposable checkout:

```powershell
codex plugin marketplace remove mayor-modder-cities2-plugins
codex plugin marketplace add $catalog
```

The marketplace add succeeded and wrote:

```text
Added marketplace `mayor-modder-cities2-plugins` from \\?\C:\Users\matt\AppData\Local\Temp\cities2-mcp-0.2.0-catalog-smoke.
Installed marketplace root: C:\Users\matt\AppData\Local\Temp\cities2-mcp-0.2.0-catalog-smoke
```

The Codex cache still contained only:

```text
C:\Users\matt\.codex\plugins\cache\mayor-modder-cities2-plugins\cities2-mcp\0.1.9
```

No `0.2.0` cache directory was installed by the CLI. Per the smoke plan, the existing `0.1.9` cache was not deleted, overwritten, or manually replaced.

Attempts to run a fresh non-interactive Codex CLI smoke with config overrides were blocked before skill execution:

- `codex plugin marketplace upgrade mayor-modder-cities2-plugins` hit local config parser errors on existing `model_reasoning_effort = "ultra"` unless overridden.
- `codex exec` with `model_reasoning_effort=xhigh` and `service_tier=fast` still logged `failed to load plugin: missing or invalid plugin.json plugin="cities2-mcp@mayor-modder-cities2-plugins" path=C:\Users\matt\.codex\plugins\cache\mayor-modder-cities2-plugins\cities2-mcp\0.1.9`.
- The same run also failed because the configured `gpt-5.6-sol` model requires a newer Codex app or CLI.

The normal public GitHub marketplace source was restored afterward:

```powershell
codex -c model_reasoning_effort=xhigh -c service_tier=fast plugin marketplace remove mayor-modder-cities2-plugins
codex -c model_reasoning_effort=xhigh -c service_tier=fast plugin marketplace add mayor-modder/Mayor-Modder-Cities2-Plugins
```

Observed restored source:

```text
source_type = "git"
source = "https://github.com/mayor-modder/Mayor-Modder-Cities2-Plugins.git"
```

## Limitations and follow-up

- The public marketplace still serves the existing published package until the generated marketplace PR from release automation runs and merges.
- The installed Codex cache did not upgrade to `0.2.0` through the CLI-only path tested here.
- Compact search found the new corpus and exact `Patch 1.6.X` page can be fetched, but the query used in the smoke did not rank the exact page ahead of `Patches` and `Patch 1.5.X`.
- A final installed-client smoke should be rerun after updating Codex app/CLI or using the plugin UI install path to install `cities2-mcp` `0.2.0` from the disposable marketplace.
